# 🧞 모둠지니

> 소원을 들어주는 모둠 요정 — **선생님 손은 가볍게, 아이들 마음은 딱 맞게.**

에듀테크 기반 AI 모둠 구성 웹앱 — [모둠구성 계획서](../모둠구성%20계획서.md) 구현체.

이름의 뜻: 지니는 **소원을 들어주고**(학생의 희망·기피 반영) **일을 대신 해주는**(교사의 모둠 편성
수고를 대신) 존재라, 이 앱이 하는 두 가지를 한 단어에 담았다.

## 오픈그래프

`npm run og` 로 `public/og.png`(1200×630)를 다시 굽는다 (`scripts/make-og.mjs`).
SVG를 `@resvg/resvg-js` 로 PNG로 변환한다 — 카카오톡·페이스북은 SVG를 og:image 로 받지 않는다.
이모지는 색 없는 글꼴로 렌더링되므로 이미지 안에서는 쓰지 않고 도형으로 그린다.
메타 태그는 `index.html` 에 있고 **절대 URL이어야** 미리보기가 뜬다.

## 저장소

`.env` 에 `VITE_FIREBASE_*` 값이 **모두** 있으면 Firestore를 쓰고, 없으면 자동으로 브라우저
localStorage에 저장한다 (`src/lib/db.js`). `.env` 는 이미 채워져 있다(`.env.example` 은 양식).

Firestore 구조: `classes/{code}` 문서 + `classes/{code}/students/{sid}` 하위 컬렉션.
localStorage 모드에서는 **같은 브라우저 안에서만** 학생 제출이 보인다.

> ⚠️ **Firestore는 배열 안에 배열을 담지 못한다**(`Nested arrays are not allowed`).
> 앱에서 `groups` 는 `[[학번,…], …]`, `history` 는 그 배열의 배열이라 그대로는 저장되지 않는다.
> `db.js` 의 `packClass` / `unpackClass` 가 저장 직전에 `[{members:[…]}, …]` 로 한 겹 감싸고
> 읽을 때 되돌리므로, **페이지 코드는 계속 중첩 배열로 다루면 된다.** 저장 형식을 바꿀 때는
> 이 두 함수만 고치면 된다.

### 보안 규칙과 익명 인증

`firestore.rules` 는 `request.auth != null` 을 요구하고, 앱은 시작할 때 `signInAnonymously` 로
익명 토큰을 받는다(로그인 화면 없음). 그래서 **콘솔에서 익명 로그인 제공업체를 켜야** 동작한다.

> Firebase 콘솔 → Authentication → Sign-in method → **익명(Anonymous)** → 사용 설정

켜지지 않았으면 앱이 그 사실을 화면에 안내한다(`getAuthError`). 켠 뒤에는 새로고침만 하면 되고
재배포는 필요 없다. 익명 인증은 누구나 받을 수 있으므로 **학급 코드 6자리가 사실상의 열쇠**다.
외부 스캐닝은 막지만 교실용 수준의 보호이지 개인정보를 담을 만한 경계는 아니다.

## 화면 흐름

| 경로 | 화면 |
| --- | --- |
| `/` | **교사 전용** — 별명 입력 → 개설 학급 대시보드 (학급 카드 클릭 시 자리표로 바로 이동) |
| `/class/new` | 새 학급 개설 · 모둠 최대 인원 설정 · 모둠 수 자동 계산 |
| `/class/:code` | 학생 접속 QR, 실시간 제출 현황·분포 통계, 결석 처리, 모둠 구성 실행 |
| `/class/:code/seats` | 자리표, 케미 타이틀, 드래그 앤 드롭 조정, 활동지 QR, 학생/교사 시점 인쇄 |
| `/s/:code` | 학생용 4단계 설문 (기본정보 → 탐구 스타일 → 희망 역할 → 교우 관계) |
| `/s/:code/room` | 학생용 학급 페이지 — 구성 전에는 대기 화면, 완료되면 자리표(내 모둠 강조) |

제출 완료 화면의 **🏫 학급 페이지로 이동하기** 로 들어간다. 학번은 `?sid=` 와 localStorage에
남으므로 다시 열어도 내 모둠이 강조된다. 교사 화면(`/class/:code`, `.../seats`)에는
**📋 학급 목록** 버튼으로 대시보드로 돌아간다.

### 링크 정리

| 용도 | 주소 | 얻는 곳 |
| --- | --- | --- |
| 교사 시작 화면 | `<앱주소>/#/` | 앱 주소 그대로 (별명 입력 → 학급 목록) |
| 교사용 학급 링크 | `<앱주소>/#/class/:code` | 학급 화면 → **🔗 교사용 링크 복사** |
| 교사용 자리표 링크 | `<앱주소>/#/class/:code/seats` | 학급 화면 → **🪑 자리표 링크 복사** |
| 학생용 링크 | `<앱주소>/#/s/:code` | 학생 접속 QR (또는 **🧑‍🎓 학생용 링크 복사**) |

교사용 링크는 즐겨찾기 해 두면 다음 시간에 바로 열린다. 학생에게 공유하면 안 되지만, 공유되더라도
교사 별명이 없는 브라우저에서는 학생용 자리표로 리다이렉트된다.

**학생은 QR로만 입장한다.** 교사 화면의 QR은 `#/s/:code` 를 가리키고, 첫 화면(`/`)에는 학급 코드
입력란이 없다. 학생 화면은 로고를 눌러도 교사 별명 화면으로 이동하지 않는다(`Layout minimal`).
학급 코드는 교사가 확인하는 용도로만 표시된다.

**학생/교사 화면 분리** — 학생용 `/s/:code/room` 에는 시점 전환·드래그 수정·인쇄·활동지 URL 설정이
없고 학생 시점(위가 칠판) 자리표 하나만 나온다. 교사용 `/class/*` 는 교사 별명(`moodum:teacher`)이
없으면 학생용 자리표로 리다이렉트되므로, 학생이 교사 URL을 열어도 교사 도구가 노출되지 않는다.
(로그인이 없는 구조라 편의를 위한 분리이지 보안 경계는 아니다.)

양쪽 모두 `subscribeClass` / `subscribeStudents` 로 구독하므로 교사가 모둠을 다시 구성하거나
드래그로 자리를 바꾸면 학생 화면에 새로고침 없이 반영된다.

**모둠 인원은 "최대 인원"** 이다. `planGroupSizes` 는 `ceil(총원 / 최대인원)` 개의 모둠을 만들고 남는
인원을 앞 모둠부터 한 명씩 채우므로, 어떤 모둠도 설정한 인원을 넘지 않는다 (예: 26명·최대 4 →
4·4·4·4·4·3·3).

## 모둠 구성 알고리즘

`src/lib/grouping.js` — 다중 재시작 힐클라이밍(8회 × 4,000 스왑). 계획서의 우선순위를 가중치로 옮겼다.

1. **기피 학생 배제** (가중치 100000 — 사실상 항상 우선하지만 절대 보장은 아니다)
2. 최근 3회 같은 모둠 감점 (최근 회차일수록 무겁게)
3. 희망 학생 반영 (상호 희망이면 1.5배)
4. 친구 편중 방지 (희망을 많이 받은 학생끼리 한 모둠에 몰리지 않게)
5. 남녀 균형 → 6. 과학 성적 균형 → 7. **과학 흥미 균형** → 8. 탐구 스타일 균형 → 9. 역할 균형

과학 흥미는 ① 모둠마다 흥미 '상' 학생이 최소 한 명 있도록, ② 흥미 '상' 인원수와 평균 흥미도가
모둠 간에 고르도록 두 방향으로 반영한다.

기피 조합을 끝내 피할 수 없으면(인원 구조상 불가능하거나 탐색이 못 찾은 경우) 자리표 상단에
경고를 띄우고 수동 조정을 안내한다 (`findViolations`). 학생 화면에도 "반영되지 않을 수 있다"고
안내한다. 26명 기준 약 0.7초.

자리 배치는 2×2 마주 보는 책상 기준으로, 발표·기록을 앞줄(칠판 쪽), 실험·관찰을 뒷줄에 배치한다.

## 자리표 시점 · 인쇄 (PDF 저장)

브라우저 인쇄 대화상자에서 "PDF로 저장"을 고르면 된다. 자리표는 `components/GroupBoard.jsx`
하나를 교사·학생 화면이 함께 쓴다.

- **학생 시점**: 위가 칠판. 학생이 앞을 보는 방향 그대로.
- **교사 시점**: 아래가 칠판(교탁), 위가 교실 뒷면. 교사가 교실 앞에서 뒤를 바라보는 방향이다.
  모둠 순서와 모둠 안 자리 순서를 뒤집어 배치만 180° 돌리고, **글자는 회전시키지 않아 바로 읽힌다**
  (CSS `rotate(180deg)` 를 쓰지 않는 이유).

## 기타

- 캐릭터 16종: 4가지 A/B 질문의 조합(활동성 E/I · 계획성 P/T · 주도성 D/S · 사고 F/L) — `src/lib/characters.js`
- 계절 테마: 접속 월에 따라 봄·여름·가을·겨울 자동 전환, 상단 칩으로 수동 변경 (`src/lib/theme.js`)
- 효과음: **기본 꺼짐**. 외부 음원 없이 WebAudio로 합성하며 상단 🔇 칩으로 켠다 (`src/lib/sound.js`)
- 케미 타이틀: 팀 능력치 중 1위가 단독일 때 그 이름을 붙이고, 공동 1위면 "균형 잡힌 만능 모둠"
  (능력치 막대 표시는 자리표에서 제외)
- 교우 관계를 모두 비우고 제출하면 🕊 "진정한 평화주의자" 이스터에그
- 학급 화면의 **🧪 샘플로 채우기** 는 미제출 학번을 임의 데이터로 채우는 시연·연습용 기능
